# homebrew-termul

Homebrew tap for [Termul Manager](https://github.com/gnoviawan/termul).

## Install

```bash
brew tap gnoviawan/termul
brew install --cask termul
```

The `termul` cask is updated automatically on each stable release by the
[`Publish Homebrew`](https://github.com/gnoviawan/termul/actions/workflows/publish-homebrew.yml)
workflow.
